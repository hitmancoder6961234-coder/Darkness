This project is a **simple Quiz Game** made using **HTML, CSS, and JavaScript**. It is designed for beginners to understand how an interactive website works. The quiz shows one question at a time, lets the user choose an answer, checks if the answer is correct or incorrect, updates the score, and displays a **"Thank You"** message when the quiz is completed.

The quiz is divided into **two rounds**, each with a different topic. After the first round is completed, the program automatically starts the second round. The colorful background, animated effects, and attractive buttons make the quiz more interesting and enjoyable to use.

This project also helps beginners learn the basic roles of **HTML** for creating the webpage structure, **CSS** for designing the appearance, and **JavaScript** for adding functionality such as changing questions, checking answers, and calculating the score. Overall, it is a simple and practical project for understanding the basics of web development.
